# BER-Prediction-in-Dual-Hop-UWOC-System-using-Random-Forest-Regression
A machine learning project that predicts Bit Error Rate (BER) in a dual-hop Underwater Optical Wireless Communication (UWOC) system using Random Forest regression based on channel parameters and compare the results from actual BER. Dataset is generated from the work "Performance Analysis Over Dual-hop UWOC System"
